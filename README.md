# stoneskill.github.io

书签页。静态文件从默认分支 `main` 的根目录，由 GitHub Pages 发布。

- 首页：https://stoneskill.github.io/
- 书签 JSON：https://stoneskill.github.io/jsons/browser_bookmark.json

首页只展示书签，并读取 `jsons/browser_bookmark.json`。仓库里只有这一份 JSON。HTML、CSS、JavaScript 为本站手写，没有使用第三方主题或模板。字体使用系统字体栈。

## GitHub Pages

- Branch: `main`
- Folder: `/`（仓库根目录）

Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `/ (root)`。

仓库里有 `.nojekyll`，页面按原文件提供，不经过 Jekyll。
