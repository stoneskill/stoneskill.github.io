一、我们如何收集和使用您的个人信息

（一）收集情况

1. 本地游戏数据

在您游玩时，本游戏会在设备本地保存关卡进度、局内记录和音效等设置。这些信息只写在本游戏的应用目录中，用于让您下次打开时继续游戏。我们不将上述内容上传到服务器。您清除应用数据或卸载本游戏后，这些本地记录会一并删除。

2. 我们不收集的信息

我们不收集您的手机号码、登录密码、姓名、身份证件类型、身份证件号码、支付账户、通讯录、短信、精确位置、相册、麦克风录音，也不收集用于识别您身份的账号信息。

本游戏没有注册、实名认证和充值功能。您不提供上述信息，也可以完整体验单机内容。

3. 设备与日志

我们没有自建账号和服务器，不为运营目的收集设备识别符、设备名称、IP 地址或访问日志，也不将这些信息用于用户画像、广告或反作弊上报。

（二）设备权限

本游戏不需要设备权限，也不向系统申请任何权限。游戏进度只保存在应用自身目录中。

（三）使用规则

  1. 本地游戏数据只用于在您的设备上实现存档、读档和设置。
  2. 这些数据留在您的设备上。您清除数据或卸载游戏后，我们将无法也不再使用它们。
  3. 我们不做包含身份识别信息的统计，也不向公众或第三方提供您的游戏记录。
  4. 若以后要将信息用于本政策未写明的目的，我们会另行征得您的同意。功能发生变化时，我们会先更新本政策。

（四）依法可不另行征得同意的情形

在以下情形中，我们可能依法处理相关信息，而无需另行征得您的授权同意：

  1. 与履行法律法规规定的义务相关的；
  2. 与国家安全、国防安全直接相关的；
  3. 与公共安全、公共卫生、重大公共利益直接相关的；
  4. 与刑事侦查、起诉、审判和判决执行等直接相关的；
  5. 出于维护您或其他个人的生命、财产等重大合法权益，但又很难得到本人同意的；
  6. 您或监护人自行向社会公众公开的；
  7. 根据您的要求签订和履行合同所必需的；
  8. 从合法公开披露的信息中收集的，例如合法的新闻报道、政府信息公开；
  9. 维护产品或服务安全稳定运行所必需的，例如发现、处置故障。

二、我们如何保存您的个人信息

  1. 游戏进度和设置保存在您的设备本地，保存期限与您保留该应用数据的时间一致。您清除数据或卸载后，本地记录即被删除。我们不在服务器端保存一份副本。
  2. 我们不将您的个人信息传输到中国境外。本政策所称“中国境内”不含中国港澳台地区。

三、我们如何使用 Cookies 和同类技术

本游戏不是网页产品。我们不使用 Cookies、Flash Cookies，也不使用广告标识、推荐算法或同类追踪技术。我们不通过这类技术收集您的信息，也不委托第三方这样做。

四、我们如何共享、转让、公开披露您的个人信息

1. 委托处理

我们不委托第三方处理您的个人信息，也不将游戏数据用于广告投放或营销。

2. 共享

我们不与关联公司或业务合作伙伴共享您的个人信息。本游戏没有需要把您的信息交给合作方才能完成的在线服务。

3. 转让

我们不会将您的个人信息转让给任何公司、组织和个人。如发生合并、收购、资产转让或破产清算，且依法涉及个人信息转让，我们会向您告知情况，并要求新的持有方继续受本政策约束；否则我们将要求其重新取得您的同意。

4. 公开披露

我们不公开披露您的个人信息。

5. 例外

根据法律法规及国家标准，在与履行法定义务、国家安全、国防安全、公共安全、公共卫生、重大公共利益、刑事侦查起诉审判和判决执行、维护生命财产等重大合法权益、您自行公开，或从合法公开渠道收集等情形下，共享、转让、公开披露个人信息可以不事先征得您的授权同意。

6. 请您谨慎向他人展示自己的设备或本地存档。其中可能包含您的游戏记录。

7. 经匿名化处理、且接收方无法复原并识别特定个人的信息，其共享、转让、公开披露无需另行通知您并征得您的同意。

五、第三方产品或服务如何获得您的个人信息

本游戏未接入第三方 SDK，没有《第三方 SDK 目录》。我们不通过广告、统计、支付、登录、语音或地图类 SDK 收集您的信息。

您的设备系统、应用商店在下载、安装、更新本游戏时自行处理的信息，适用该系统或应用商店自身的隐私政策，不由本政策约束。

六、我们如何保护您的个人信息

  1. 游戏数据存放在应用沙箱或系统分配的应用目录中，由操作系统的隔离机制保护，不上传到我们的服务器。
  2. 互联网环境并非绝对安全。本游戏不依赖服务器保存您的存档，因此不存在由我们侧服务器泄露该存档的情形。请您保管好自己的设备。
  3. 如发生依法需要告知的个人信息安全事件，我们将按法律法规要求，以应用内提示或其他合理方式告知您事件情况、可能的影响、处置措施和可采取的建议，并按监管部门要求上报。

七、您如何管理您的个人信息

本游戏没有账号，因此没有账号资料页或注销入口。您可以通过本机操作管理本地数据：

1. 访问与更正

游戏进度和设置显示在本游戏内。您可以在游戏中继续游玩或修改音效等设置。

2. 删除

您可以在系统设置中清除本游戏的应用数据，或直接卸载本游戏。清除或卸载后，保存在本地的进度和设置将被删除。在我们违反法律规定处理信息、您不再使用本游戏，或我们终止运营时，您也可以通过本政策载明的方式联系我们。

3. 撤回同意

本游戏不申请设备权限，也不收集需要您另行授权的个人信息。您可以清除本游戏的应用数据或卸载游戏，以删除保存在本地的记录。

4. 注销

本游戏不创建用户账号，因此没有需要注销的账号。卸载本游戏即停止使用，本地个人游戏数据随卸载删除。

5. 响应您的请求

如您无法通过上述方式完成操作，可以通过本政策载明的联系方式与我们联系。为保障安全，我们可能先验证您的身份。对合理请求，我们原则上不收费；对多次重复、超出合理限度的请求，可能收取必要成本。对无端重复、需要过多技术手段、损害他人合法权益或不切实际的请求，我们可能拒绝。我们通常在十五个工作日内回复。

6. 无法响应的情形

与履行法定义务、国家安全、国防安全、公共安全、公共卫生、重大公共利益、刑事侦查起诉审判和执行判决相关的请求；有充分证据表明您存在主观恶意或滥用权利的；为维护您或其他个人的生命、财产等重大合法权益但又很难得到本人同意的；响应请求将严重损害您或其他个人、组织合法权益的；涉及商业秘密的，我们可能无法响应。

八、我们如何处理未成年人的个人信息

我们重视未成年人保护。本游戏不主动收集未成年人的姓名、身份证件号码、手机号码等个人信息，也不建立未成年人账号。

未满 14 周岁的未成年人应在父母或其他监护人阅读本政策并同意后使用本游戏。已满 14 周岁未满 18 周岁的未成年人，应由监护人同意或自行同意后使用。

监护人如发现未成年人在未经同意的情况下向我们提供了个人信息，请通过本政策载明的方式与我们联系。
