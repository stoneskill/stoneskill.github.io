02 / About

关于

我叫李强强，GitHub 上的用户名是 stoneskill。我在浏览器厂商做引擎移植：把 Chromium 和 Firefox 带到还需要它们的体系结构上，并让这些移植能跟着上游继续构建。

  • Chromium 这一侧是 MIPS64el 与 ARM64。公开仓库 stoneskill/chromium 的简介是 “The official GitHub mirror of the Chromium source”。
  • Firefox 这一侧是 MIPS64 与龙芯。公开仓库 stoneskill/firefox 的简介是 “Firefox source tree for Loongson 3”。

另外还有一份公开的 ungoogled-chromium fork。其余仓库都在 GitHub 主页上，这里不逐个展开。账号从 2014 年放在 GitHub 上。

Browser vendor engineer. I work on the Chromium port for MIPS64el and ARM64, and the Firefox port for MIPS64 and Loongson.
